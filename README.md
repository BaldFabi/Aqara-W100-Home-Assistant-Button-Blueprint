# Aqara W100 Home Assistant Button Blueprint

This blueprint allows you to easily set up automations for the Aqara W100 buttons. You can configure actions for single press, double press, and long press events.

You need to import this blueprint into your Home Assistant instance and then create automations based on the button events.
The [documentation](https://www.home-assistant.io/docs/automation/using_blueprints/) provides more information on how to use blueprints in Home Assistant.
